## The scorers

- The control's score-diag-first.mjs is its score.mjs with the host Go module cache mounted read-only (GOMODCACHE, GOPROXY=off, GOFLAGS=-mod=mod) and its output under official-diag-first/: otherwise the same (checked: identical apart from those).
- IC's score.mjs (rep1p) is the control's score.mjs plus the verifier log's path in its output: checked: identical apart from that. Both mount the same official tests (theme_d5_w9…/steps/round-N/tests) in the same image.

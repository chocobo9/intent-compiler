# Instrument audit on the existing runs (2026-10-23 evening, no model calls)

## 1. Where guard expected values come from (observed)

| run | guards | assertions: verbatim (stated in text) | derived (reference script / model derivation) | computed |
|---|---|---|---|---|
| rep1g (R1) | 30 | 11 | 48 | 0 |
| ic15 R1–R3 | 106 | 62 | 141 | 4 |

About 70% of guard assertions are `derived`: the expected value was produced by a model-written reference script or
the formalizer's derivation, not quoted from the text. This is the G77 class (R3: a derived expectation, correct under
R2's text, superseded by R3's text, treated as a regression). A guard whose expectation is derived is only as valid as
the derivation and the text it was derived from; retiring it must follow the modification record (DESIGN §12j.7 item
11). Validity against the official oracle per guard needs the revision gold set and a guard→case mapping; not done here.
